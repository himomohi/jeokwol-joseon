# 적월조선

조선 환상 배경의 단독 플레이 탑다운 액션 RPG. 한양 근교에서 길을 나서 싸우고, 노획하고, 장비하며, 전직하고, 마을로 돌아온다. 세계는 시드 기반으로 다시 그려지며 마을로 돌아온다고 리셋되지 않는다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:47261` 을 연다.

```bash
npm run build      # 타입 검사 후 dist 생성
npm run preview    # 빌드 미리보기 (동일 포트)
npm run typecheck  # tsc만
```

런타임 의존성은 없다. Phaser / Pixi / Three / 물리 엔진 / 생성형 이미지 API를 쓰지 않는다. 아트는 코드로 그린 실루엣·무기 형태를 캐시한다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 좌클릭 또는 J | 기본 공격 (1번 초식) |
| 1–8 | 초식 |
| E | 가까운 NPC와 대화 / 전직·상점 |
| F | 가까운 드롭 줍기 (가까이 가면 자동 습득도 됨) |
| R | 마을에서 휴식 (체력/마력 회복, 저장 시도) |
| I | 행낭 |
| K | 초식 패널 |
| C | 몸가짐(스탯·전직 조건) |
| M | 탐험 지도 (안개) |
| Esc | 멈춤 / 저장 |
| P | WebGL 블룸·CRT 후처리 켜기/끄기 |
| F1 | 도움말 |

행낭에서 아이템 클릭 = 장착 또는 사용. 우클릭 = 버린다. 장비는 스탯과 캐릭터 실루엣(무기·포 색)을 함께 바꾼다.

## 전직

기본 직: 무사, 궁수, 도사, 의원, 도적, 기병.

각 직은 마을 교관에게 말을 걸어 8급 이후 두 갈래로 전직한다. 한쪽은 급수만, 다른 쪽은 지역 우두머리(적월호랑이, 산적왕, 폐사 주지, 늪 이무기 등) 처치 표식이 필요하다. 전직하면 해당 길의 초식 8개가 열린다. 툴팁 숫자는 시뮬레이터 위력·재사용·마력과 같다.

## 저장

로컬 `localStorage` 세 자리 (`jeokwol.slot.0` … `2`). 멈춤 메뉴의 저장, 또는 마을에서 R 휴식 시 기록한다. 용량 초과·파손 시 한글로 실패 이유를 보여 주고 시뮬은 계속한다. 클라우드 저장은 없다.

불러오기는 표지에서 자리를 고른 뒤 「불러오기」. 위치·행낭·전직·안개·처치 표식이 유지된다. 필드 졸개는 시간이 지나면 다시 나타나지만, 우두머리와 마을 NPC는 리셋되지 않는다.

## 세계

시드+좌표 질의로 바이옴을 섞는다: 한양 근교, 산악, 대나무숲, 강변, 늪/습지, 설산, 폐사/원혼, 그리고 길·마을. 타일 청크는 예산 초과 시 LRU로 비우고 같은 시드로 다시 만든다. 이음은 좌표 해시로 맞춘다.

고정 타임스텝 120Hz, 렌더는 보간한다. 데미지·경험·노획·장착·저장은 시뮬만 결정한다. 월드/아트/전투/노획 RNG는 스트림이 분리되어 있다.

## 알려진 한계

- 멀티플레이, 깊은 제작, 클라우드 세이브는 없다.
- 아트는 스프라이트 시트가 아니라 절차적 실루엣이다. 멀리서 직·종족은 읽히지만 세밀한 한복 문양은 없다.
- 청크 바깥 액터는 메모리에서 내리므로, 아주 멀리 두고 온 드롭은 사라질 수 있다.
- WebGL 컨텍스트가 죽으면 후처리 없이 Canvas2D로 그린다. UI 텍스트는 월드 버퍼에 들어가지 않는다.
- 좁은 화면에서는 배율을 낮추고 스킬 바가 가로 스크롤된다.

## 검증

부팅 시 콘솔에 직/전직/초식/적/보스/바이옴/물산 카운트가 찍힌다. 새 인물 → 이동·전투 → 드롭·경험 → 장착 시 외형·스탯 변화 → 교관 전직 → 지역 이동 후 마을 복귀 → 저장/재개가 플레이 루프다.
