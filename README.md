# 적월조선

조선 환상 배경의 단독 플레이 탑다운 액션 RPG. 무명촌에서 동녘으로 길을 나서 싸우고, 노획하고, 장비하며, 한성 교관에게 전직하고, 거점으로 돌아온다. 세계는 시드 기반으로 다시 그려지며 마을로 돌아온다고 리셋되지 않는다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:47261` 을 연다.

```bash
npm run build      # 타입 검사 후 dist 생성
npm run preview    # 빌드 미리보기 (동일 포트)
npm run typecheck  # tsc만
npm run smoke      # 시뮬 B루프: 스폰→공격→처치→루트→장착→저장/불러오기 (<10초)
```

런타임 의존성은 없다. Phaser / Pixi / Three / 물리 엔진 / 생성형 이미지 API를 쓰지 않는다. 월드·인물 아트는 코드로 그린 실루엣(관절·재료·형태)을 Canvas에 캐시하고 WebGL 후처리를 얹는다. PNG/SVG는 파비콘 등 예외만.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 좌클릭 또는 J | 기본 공격 (1번 초식) |
| 1–8 | 초식 |
| E | 가까운 NPC와 대화 / 전직·상점 |
| F | 가까운 드롭 줍기 (가까이 가면 자동 습득도 됨) |
| R | 거점에서 휴식 (체력/마력 회복, 저장 시도) |
| I | 행낭 |
| K | 초식 패널 |
| C | 몸가짐(스탯·전직 조건) |
| M | 탐험 지도 (안개) |
| Esc | 멈춤 / 저장 |
| P | WebGL 블룸·CRT 후처리 켜기/끄기 |
| F1 | 도움말 |

행낭에서 아이템 클릭 = 장착 또는 사용. 우클릭 = 버린다. 장비는 스탯과 캐릭터 실루엣(무기·포 색)을 함께 바꾼다.

## 전직

기본 직: 무사, 궁수, 도사, 의원, 도적, 기병.

무명촌 교관은 한성으로 길을 알려 준다. 한성에서 힌트를 듣고, 스무~스물두 급에 교관의 자리를 밟으면 `trainerFlag`가 열린다.

| 전직 | 급수 | 자리 |
| --- | --- | --- |
| 검객 | 20 | 한성 무관청 |
| 창병 | 20 | 동문 군영 |
| 신기전(화살사수) | 20 | 강변 병기창 |
| 백발(신궁) | 20 | 대숲 오두막 |
| 천문(술사) | 20 | 관상감 |
| 부적사 | 20 | 폐사 사찰 |
| 침(명의) | 20 | 혜민서 |
| 독객 | 22 | 약방 지하 / 늪 약초원 |
| 흑의(자객) | 20 | 밤골목 |
| 금강(도굴) | 22 | 암자 |
| 염화 기창 / 마궁 | 22 | 산 수련장 |

전직하면 해당 길의 초식 8개가 열린다. 툴팁 숫자는 시뮬레이터 위력·재사용·마력과 같다.

## 저장

로컬 `localStorage` 세 자리 (`jeokwol.slot.0` … `2`). 멈춤 메뉴의 저장, 또는 거점에서 R 휴식 시 기록한다. 용량 초과·파손 시 한글로 실패 이유를 보여 주고 시뮬은 계속한다. 클라우드 저장은 없다.

불러오기는 표지에서 자리를 고른 뒤 「불러오기」. 위치·행낭·전직·안개·처치 표식이 유지된다. 필드 졸개는 시간이 지나면 다시 나타나지만, 우두머리와 마을 NPC는 리셋되지 않는다. 사망 시 들른 거점(무명촌·한성·초소·나루·암자)으로 일어난다.

## 세계

메인 패스는 한 줄기 길이다.

무명촌 → 근교 벼밭(1–5) → 돌담 고갯길 → 산적 야영 → 산적두목(7–8) → 한성 외곽 → 대숲(9–14) / 강변(12–17) → 늪(16–22) → 산악(20–26) → 설산(26–32) → 폐사/원혼(30–36) → 원혼대승 → 엔드 균열.

거점: 무명촌, 한성 외곽, 초소·뱃사공 나루·암자. 열린 지형은 동시 적 8–14, 좁은 고갯길·대숲·폐사는 5–9. 스폰 가족은 pest / bandit / bamboo / river / swamp / mountain / snow / wraith.

난이도 벽: 첫 보스 산적두목 → 늪 독 → 전직 게이트 → 설산 한기(이속·틱) → 원혼 정예.

시드+좌표 질의로 바이옴을 섞는다. 타일 청크는 예산 초과 시 LRU로 비우고 같은 시드로 다시 만든다. 이음은 좌표 해시로 맞춘다.

고정 타임스텝 120Hz, 렌더는 보간한다. 데미지·경험·노획·장착·저장은 시뮬만 결정한다. 월드/아트/전투/노획 RNG는 스트림이 분리되어 있다.

## 아트 방향 (최종 16색)

제품 잠금 팔레트다. 실루엣(철릭·갓·전립·미늘갑)이 먼저 읽히고, 환경은 낮은 채도, `blood_main`/`blood_hot`과 횃불은 생명·VFX·UI·광원만 쓴다. 아웃라인은 이웃 스와치지 순수 `#000`이 아니다. 키라이트는 북서. 후처리를 꺼도(P) 탑다운으로 직·종족이 구분된다. 상수는 `src/art/palette.ts`의 `LOCKED_16`이며 코드젠 아트·HUD·후처리 화면 밖 색이 같은 16색을 참조한다.

## 알려진 한계

- 멀티플레이, 깊은 제작, 클라우드 세이브는 없다. 저장은 브라우저 `localStorage` 한 자리(0–2)다.
- 아트는 스프라이트 시트가 아니라 절차적 실루엣이다. 멀리서 직·종족은 읽히지만 세밀한 한복 문양은 없다.
- 청크 바깥 액터는 메모리에서 내리므로, 아주 멀리 두고 온 드롭은 사라질 수 있다.
- WebGL 컨텍스트가 죽으면 후처리 없이 Canvas2D로 그린다. UI 텍스트는 월드 캔버스에 넣지 않는다(HUD·대화·지도 라벨은 `#ui-root`).
- 좁은 화면에서는 배율을 낮추고 스킬 바가 가로 스크롤된다.
- 몬스터 카탈로그는 플레이 가능한 규모(원형 57·보스 7)이며, 이름 별칭만 있는 종이 있다.

## 검증

부팅 시 콘솔과 표지에 콘텐츠 카운트가 찍힌다. `npm run smoke`는 시드 1에서 동쪽 벼밭 이동 → 처치 → 경험/엽전 → 무사→검객 전직(20급·무관청 표식, 초식 8) → 스냅샷 재개를 확인한다.

확인된 규모: 기본 직 6 + 전직 12 (카탈로그 별칭 포함 조회 ID 30), 전직당 초식 8(카탈로그 96 + 기본 24 = 120), 적 원형 57·보스 7, 시뮬 바이옴 9 + 카탈로그 8, 루트 테이블 20+(별칭 포함). `tsc`와 `vite build` 통과.

카탈로그 패키지는 `src/content/`에 병합했다. 시뮬 정본 ID(`musa`, `gungsoo`, `boss_bandit`, `hanyang`/`road` 등)는 그대로 두고, 조사용 별칭만 얹었다.

| 모듈 | 정본 | 카탈로그 별칭 |
| --- | --- | --- |
| `jobs.ts` / `skills.ts` | 18직 · 120초식 | `gungsa`, `seungbyeong`, `baekbal` 등 |
| `enemies.ts` / `monsters.ts` | 스폰 배열 유지 | 57 ID → `ENEMY_BY_ID` |
| `world.ts` / `biomes.ts` | 맵 9바이옴 | 한성골목·지리산·원혼궁 등 8 |
| `loot-tables.ts` | 가족/보스 테이블 | `loot_hanseong_alley` 등 20 ID |

플레이 루프: 새 인물 → 벼밭 전투 → 드롭·경험 → 산적두목 → 한성 힌트 → 교관 표식·전직 → 지역 이동 후 거점 복귀 → 저장/재개.
